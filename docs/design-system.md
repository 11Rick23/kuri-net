# kuri-net のデザイン

## 方針

個人のプロフィール、制作実績、日常的に使うツールを、同じ文字組みと配色でつなぐ。既存の文章・データ・機能を保ちながら、余白と大きさで情報の優先順位を作る。

主な参考は [re-presentation.jp](https://re-presentation.jp/)。詳細な観察記録は [デザイン調査](../output/design-research/re-presentation/DESIGN.md) と [調査項目・出典](../output/design-research/re-presentation/README.md) にまとめている。

## 参考から取り入れたもの

| 要素 | kuri-net での使い方 | 理由 |
| --- | --- | --- |
| 明るい紙面と濃い文字、広い外側余白 | 共通キャンバスと読み幅 | 画像が少ないページも、情報の階層で成立させる |
| Jost と Zen Kaku Gothic New | 欧文見出しと日本語本文 | 幾何学的な欧文と読みやすい日本語を組み合わせる |
| 文字を大きく使う導入 | ホームの挨拶、プロフィール名 | 既存の内容だけで各ページの入口を作る |
| 行の選択時に面が横へ広がる動き | ホーム・作品・アプリのリンク | クリックできる範囲と現在の操作対象を示す |
| 小さな移動を伴う出現 | 画面外の紹介セクション | スクロールの進行を補助する |
| 項目を行として扱う構成 | 作品・アプリ・活動の一覧 | 内容量の違いを許容し、箱の反復を減らす |

アクセントカラーはライト・ダーク共通で `#F7A481` を使う。3Dオープニング、スクロールの置き換え、長い遷移待ちは導入せず、既存のリンク・ボタン操作を維持する。装飾目的の説明文や英語ラベルは増やさない。

## 調整する場所

| 変更したいもの | 編集する場所 |
| --- | --- |
| ライト／ダークの全体配色 | `src/shared/styles/tokens.css` の `.latte` / `.macchiato` |
| 本文・見出しフォントの役割 | 同ファイルの `--font-body` / `--font-display` |
| 使用するフォントの読み込み | `src/app/layout.tsx` の `next/font/google` |
| ページ幅・外側余白・セクション間隔 | `--site-content-width` / `--site-page-gutter` / `--site-section-gap` |
| ヘッダーの高さ | `--site-header-height`。モバイル値も同時に調整する |
| ヘッダーロゴのサイズ・線色 | `--site-logo-size` / `--site-logo-ink` |
| 動きの長さ・加減速 | `--site-duration-*` / `--site-ease` |
| 共通見出し・入力境界・フォーカス | `src/app/globals.css` |
| ページ固有の構図 | 各 feature の CSS Module |

配色には用途を表す名前を使う。`--site-canvas` は画面全体、`--site-surface` は操作面、`--site-ink` は本文、`--site-muted` は補助文、`--site-line` は区切り線、`--site-control-line` は入力の境界、`--site-accent` は選択・フォーカス。成功・警告・エラーは専用の意味色を持つ。

既存ツールの `ctp-*` クラスは `globals.css` から新しい変数へ接続する。新規ページでは `site-*` を使い、既存の状態表示やボタンを一括で無関係に書き換えない。`next-themes` の `latte` / `macchiato` クラス名は互換のため維持する。

## ロゴ

縦線と斜線を分けたKを使う。形の間の余白と直線を、サイトの構図に合わせる。

- 通常版は `public/logo.svg`。アクセントは `#F7A481`、輪郭は黒。テーマによらず共用する。
- ヘッダーは共通の `LogoMark` SVGで表示する。ホームでは `public/logo.svg` と同じオレンジの塗りと黒の細い輪郭を使い、他ページでは `public/logo-outline.svg` と同じ形のアウトラインをライトは黒、ダークは白で表示する。表示サイズは40px、リンクの操作領域は44px以上。導入アニメーションでは、ヘッダーへ移動する間に輪郭からカラーへ切り替わる。
- `public/logo.png`（512px、共有画像）と `public/favicon.ico`（16 / 32 / 48px）は通常版から書き出したファイル。通常版の形や色を変更した場合は併せて再生成する。
- アイコンと共有画像の参照先は `src/app/layout.tsx` のmetadataで管理する。

## ページ構成

- **Home:** 左に挨拶とお知らせ、右に3つのページリンク。お知らせは既存の本文書体・面色・細い境界線で囲み、幅512px（狭い画面では利用可能な幅）・高さ200pxで最新1件を表示する。日付はタイトルの横に置き、タイトルは1行、本文は3行まで表示して長文を「…」で省略する。「全てのお知らせ」は本文下に専用の余白を取らず右下に重ね、共通の面色を背景にして読めるようにする。共通モーダルでは最新分を含む全文を表示し、件数は表示しない。挨拶を主役に保つため、日付と本文は小さく控えめにし、枠内の24pxの余白で読みやすく区切る。追加の装飾やアニメーションは使わない。狭い画面では上下に並べる。
- **Profile:** 最初の画面は名刺を中央に配置し、本文、興味分野、活動はスクロールした先に続ける。名刺は通常の1.22倍（狭い画面では1.12倍）の大きさで上方から入り、1.65秒で中央へ移動する。中央で0.3秒静止した後、約1秒かけて通常サイズ・正面へ落ち着く。全体を3秒とし、浮いた名刺を手渡されてから下ろす感覚を表現する。登場後は画面下部中央の下向きアイコンを600msで表示し、自己紹介へのアンカーリンクにする。登場とアイコンの表示待ち時間は共通のCSS変数で揃え、動きを減らす設定ではアイコンも即座に表示する。登場アニメーションは操作用の回転とは別の親要素に適用し、登場中はポインター操作を受け付けない。キーボードフォーカス時と「動きを減らす」設定時は即座に静止表示する。
- **Works:** 実画像と説明を横に並べる。画像のない作品は文字だけの行とし、空の画像枠を作らない。詳細モーダルには既存の情報・動画・PDFを残す。
- **Apps:** アプリ名と説明、開く操作を横長の行へまとめる。各ツールの入力・設定・結果は従来のまとまりを維持する。

## 動きと操作

Profileの本文は生い立ち、コンピューターへの関心、高校生活、大学での活動を短い概要で紹介し、原稿の詳細は文章内で展開する。本文は最大740pxで中央に置き、本文20px・モバイル18px、冒頭の挨拶24〜32px・モバイル24pxを保つ。名刺部分には背景図形を置かず、本文部分の背景に円・楕円・正方形・長方形・正三角形・二等辺三角形を回転して配置する。SVGの縦横比を保ち、図形をゆがめない。本文sectionを幅制限のあるPageContainerの外に置き、PC・スマートフォンとも背景を画面の左右端まで広げる。文章の左右余白はsite-page-gutterで保つ。大きな図形を14個、本文上端から-180〜6,840pxの固定位置に用意する。文章の展開では既存図形を動かさず、伸びた領域の図形が見えるようにする。短い本文の外側は切り取り、背景自体がページを伸ばさない。各図形は左右端を基準に自身の幅の36〜42%を外へ出し、大きな色面を中央まで伸ばす。既存のピーチ・青・青緑・紫・黄・赤・ミント・オレンジの各色12%と不透明な背景色88%から淡い塗り色を作る。塗りは不透明にし、重なった部分は手前が奥を隠す。輪郭だけを3pxのblurでやわらげる。幅は1,160〜1,300pxを基準にし、幅1100px以下は80%、767px以下は68%に縮小する。ただし、広いPCでも中央が空きすぎないよう画面幅の88%を下限とする。図形はカーソルに合わせて横8px・縦6px以内で緩やかに動く。本文の選択・リンク・スクロールを妨げず、キーボード操作の対象にしない。タッチ操作時は静止する。本文の指標はENERGY 1 / RHYTHM 2 / MOTION 1とする。

本文の末尾には画面高の28%（最小200px・最大360px）の余白を設ける。この余白は背景を持つ本文sectionの内側に置き、外側のmainに下余白を重ねない。図形背景がページ最下部まで続くようにする。

本文中の言葉から18項目の詳細を開ける。詳細はその言葉を含む段落の文末へ文章として加え、複数項目の並びは本文の語順に合わせる。同時展開数に上限を設けず、クリック・Enter・Spaceで個別に展開と折りたたみを切り替える。フォーカスは操作した言葉に保ち、展開中はピーチ色のハイライトと実線の下線で示す。追加文は本文の95%の文字サイズと少し控えめな文字色で区別し、冒頭の挨拶の追加文は通常の本文サイズにする。各ボタンのaria-expandedとaria-controlsで状態と対象を伝える。追加文を枠やカードで囲まず、本文の流れに置く。

詳細は、必要な行の高さを360ミリ秒で確保してから、タイプするように増える。折りたたみ時は末尾から文字を消した後、余白を360ミリ秒で縮める。文字の増減中は全文の折り返し位置を保ち、日本語の濁点や絵文字のまとまりを壊さないよう書記素単位で表示する。文字の表示は最長1.8秒、削除は最長0.9秒とし、初めと終わりをゆっくり、途中を速くする。途中で再操作した場合も現在の文字数・高さから切り替える。詳細内のリンクも同じ順序で表示し、未表示の文字や縮小中の詳細は読み上げとフォーカスの対象から外す。展開中の単語へのマウスホバー・キーボードフォーカスで、表示済みの追加文を薄いピーチ色で強調する。「動きを減らす」設定では文字と高さの増減を即座に完了し、図形の追従とハイライトの遷移も停止する。

状態変化は160〜280ms、セクションの出現は800msを基準とする。画面外の要素の先頭が画面の下端から96px入ると、24px浮かび上がりながら表示する。JavaScript実行前や利用できない場合に本文を隠さず、最初から画面内にある内容も表示したままにする。

ホバー効果はマウスを利用できる環境で有効にし、キーボードには明確なフォーカスと選択面を用意する。OSの `prefers-reduced-motion` が有効な場合は出現・移動・滑らかなスクロールを抑える。

ヘッダー・ホーム・作品一覧・アプリ一覧のハイライトは、クリック時に280msで2回点滅し、操作への反応を示す。フェードを使わず、表示・非表示を瞬時に切り替える。文字やフォーカス枠は点滅させず、連続クリック時は最初から再生する。「動きを減らす」設定では点滅を省く。

ホーム・アプリ一覧のページ遷移と作品詳細の表示は、点滅が見えるよう完了後に実行する。ヘッダーはページ遷移後も残るため、そのまま遷移する。タッチ操作でも点滅中はハイライト面を表示する。修飾キーで別タブを開く操作は通常どおり実行し、「動きを減らす」設定では画面切り替えも待たせない。

ヘッダーの操作領域は44px以上。モバイルではロゴ・ページ選択・操作ボタンを一段に並べ、高さ72pxとする。幅640px以上ではページリンクを横並びにし、640px未満では「Page」と右向きのSVG矢印から円形メニューを開く。ボタン位置から円が飛び出し、ヘッダーの下で最大直径360pxの円に広がる。画面の幅と高さに合わせて円を収め、3つのページ名を円内の中央に縦並びで配置する。背景には3pxの薄いぼかしを加え、円の開閉に合わせて表示・解除する。背景と文字には反転配色を使い、円の外側には本文を残す。PC・モバイル共通で、ホバー・キーボードフォーカス・押下時にオレンジの面が左から右へ広がる。現在のページは同じオレンジの塗りで示し、文字には濃い色を使う。開閉は同じ800msのタイムラインを正逆再生する。開くときは円が先に広がり、文字が80msずつ遅れて登場する。閉じるときは文字が逆順に戻り、背景がボタンへ縮む。途中で押し直しても現在位置から折り返す。背景の操作・スクロールは閉じ終わるまで止め、ページ選択・Pageの再クリック・円の外側のクリック・Escape・履歴移動で閉じる。画面サイズの変更と「動きを減らす」設定では動きを省略する。モーダルとアプリメニューのEscape、フォーカス循環、閉じた後の復帰、背景のスクロール抑止は既存処理を維持する。

## 設計の判断

プロフィールの名刺は、半径16pxの丸角を持つ表面・裏面と、その間の四辺と各角を8分割した側面を同じ3D空間に配置し、丸角まで連続した薄い側面を表現する。側面の見え方は回転と遠近法に任せ、操作で傾きが反転すると上辺・左辺も現れる。光源を左上に揃え、上辺・左辺を明るく、下辺・右辺を暗くする。表面の縁の明暗と裏面の接地影・落ち影を組み合わせる。参考は [Material Designの縁・光・接地影](https://m1.material.io/style/icons.html) と [高さによる影の違い](https://m1.material.io/material-design/elevation-shadows.html)。この陰影表現は名刺に限定する。ロゴは透過画像 `public/profile/logo-skelton-white.png` / `public/profile/logo-skelton-dark.png` をテーマに合わせて使う。

厚みはクレジットカードのような薄さを目安に、画面幅に応じて2.5〜6pxとする。初期状態は正面向きで、マウスのホバー時は各軸±5度、ドラッグ中は各軸の角度を制限せず回転できる。ドラッグを離す直前80msの速度を使い、速く離した場合は慣性回転する。速度は指数的に減衰し、十分遅くなったら各軸を同じ見た目の±180度以内に正規化して正面へ滑らかに戻る。静止してから離した場合と操作キャンセル時には慣性を付けない。慣性・復帰中のホバーは無視し、掴み直すとその場から操作へ切り替える。角度は1フレームに1回だけ描画する。ドラッグ中は補間を挟まず固定した開始位置から追従し、ホバー・復帰だけを時間に応じて補間する。掴んだ瞬間の表示角度を起点にし、ドラッグ中のホバー入力は無視する。カードの幅・高さの2倍の距離のドラッグを1回転に対応させる。裏面の中央にはヘッダーと共通の `LogoMark` を置き、ロゴ内部全体を地色より少し暗く塗り、暗い輪郭と細い明るい縁で面全体を浅く彫り込んだ刻印を表現する。裏面を含めて何周でも回せ、離すと各軸半周以内で表面へ戻る。反射は角度に対して周期的に変化させ、1回転の境界でも連続させる。スマホでは横方向のドラッグに対応し、縦スクロールとピンチズームを維持する。[Interactive 3D Metal Card](https://codepen.io/kirkegaard/pen/raVqGwa)の金属表現を参考に、ライトでは落ち着いたシルバー、ダークではグラファイト色を使う。表面のヘアラインは素材の模様として固定し、斜めの明暗帯は12pxぼかした独立した反射層として傾きに追従させる。円錐・放射グラデーションも18pxぼかして同じ位置・角度に追従させ、すべての反射を常時淡く表示する。文字・ロゴは反射より前面に配置する。操作の開始・終了で濃さを切り替えない。光の位置と角度は450msで滑らかに追従・復帰する。強い白飛びや黒い反射帯を避け、文字の読みやすさを優先する。「動きを減らす」設定時も淡い反射を維持し、動きだけを止める。

antislop の指標は **ENERGY 2 / RHYTHM 2 / MOTION 2**。見出しの大小と非対称の構成で表情を出し、ツールの操作領域は安定した配置を優先する。design-taste-frontend は構図・文字の階層の参考として扱い、追加素材や文章による情報量の増加は避ける。

色・書体・余白を共通化しつつ、全ページを同一のカードグリッドへ揃えない。既存ロゴ、作品画像、本文の違いがそれぞれのページの特徴になるようにする。
